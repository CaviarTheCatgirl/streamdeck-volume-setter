i How It Works
Profile Syncing: When multiple buttons share the same Profile ID, pressing any one of them will update all buttons with that ID. Images uploaded here will also sync across all buttons.

Volume Toggle: Each press switches between Level 1 and Level 2. The button shows the current volume (or L/R balance if different).

Custom Images: Upload images for each state. When synced, all buttons with the same Profile ID will share these images.
